# Web 品牌 Logo 使用规范

## 素材来源与状态

- 项目操作方于 2026-07-28 提供 `logo.jpeg`，并用于本次正式 Web 接入。
- 原始文件 SHA-256：`859b01656d9926d3a25ff9d42aaf07b2e106b637a3812a92de377ff1cbec7291`。
- 原始文件只有 200×200 像素且带暖白色 JPEG 背景。生产资产 `logo.svg` 从唯一深青色连通区域机械提取轮廓，不使用生成式重绘，不改变环形结构和交叠关系。
- 如果公司另有品牌法务或市场审批流程，发布负责人仍需完成该流程；本文件记录的是项目操作方提供素材和技术接入状态。

## 生产资产

- `logo.svg` 使用透明背景和 800×800 `viewBox`，可以无损缩放。
- 图形主色为从源图核心像素取样得到的 `#204957`。
- 实际图形边界约为 `x=153–647`、`y=154–645`。四周约 19% 的画布空间属于 Logo 自带安全留白，不得通过修改 `viewBox`、负外边距或容器裁剪移除。
- 页面必须保持原始正方形比例并使用 `object-contain`；禁止拉伸、旋转、拆分四个环、改变线宽或添加重复背景纹理。

## 使用位置和建议尺寸

| 位置             | CSS 画布尺寸 | 说明                                   |
| ---------------- | ------------ | -------------------------------------- |
| 桌面导航         | 36×36        | 与平台显示名一起使用                   |
| 桌面登录页       | 80×80        | 作为主要品牌识别，不增加快速动画       |
| 窄屏登录页       | 48×48        | 与平台显示名一起使用                   |
| Agent 消息头像   | 32×32        | 装饰性图片，对辅助技术隐藏             |
| 空状态           | 64×64 或以上 | 保留完整留白，不作为重复水印           |
| Agent 处理中状态 | 32×32        | 只允许低频呼吸；低动态模式下必须为静态 |

React 页面统一通过 `BrandLogo` 组件使用该资源。非装饰 Logo 提供“平台显示名 + 标志”的替代文本；
Agent 头像和处理中图形使用 `aria-hidden`。资源加载失败时，组件回退到可访问的平台名称首字母标记。
