## ADDED Requirements

### Requirement: 纯前端模型选择预览

Web 会话输入区 SHALL 提供一个模型选择按钮和单选列表。列表 SHALL 包含自动选择、GPT-5.6 Sol、GPT-5.6 Terra、Claude Opus 5、Claude Sonnet 5 和 Gemini 3.6 Flash，并默认选中自动选择。当前选择 SHALL 在按钮文案和列表选中态中保持一致，但 MUST NOT 改变消息提交载荷、真实 Provider 或模型运行配置，也 MUST NOT 写入浏览器持久化存储。列表 MUST NOT 显示“界面预览，暂不影响实际模型”或同类免责声明。

#### Scenario: 打开模型列表

- **WHEN** 用户在可编辑的会话输入区激活模型选择按钮
- **THEN** Web 应用在输入区上方展示规定的模型列表并明确当前选中项，不显示预览提示或免责声明

#### Scenario: 切换展示模型

- **WHEN** 用户从列表中选择另一个演示模型
- **THEN** 列表关闭，模型按钮显示新名称，后续再次打开时该项仍被标记为当前选择

#### Scenario: 选择后发送消息

- **WHEN** 用户选择任一演示模型并发送消息
- **THEN** Web 应用仍只按既有契约提交消息文本和客户端消息标识，不提交演示模型标识，也不宣称真实模型已切换

#### Scenario: 刷新页面

- **WHEN** 用户切换演示模型后刷新页面或重新进入应用
- **THEN** 选择器恢复前端默认项，且不从持久化存储恢复模型偏好

#### Scenario: 使用键盘操作

- **WHEN** 键盘用户聚焦模型选择按钮并使用 Enter、Space、方向键或 Escape
- **THEN** 用户可以打开列表、移动并确认选择或关闭列表，焦点返回行为可预测且当前选择可由辅助技术识别

#### Scenario: 窄屏输入消息

- **WHEN** 用户在窄屏设备查看会话输入区
- **THEN** 模型按钮和发送按钮保持可见可用，辅助键盘提示可以隐藏，模型名称不会撑破输入区布局

#### Scenario: 输入区禁用

- **WHEN** 会话已归档或消息输入区因既有状态不可编辑
- **THEN** 模型按钮同步禁用，任何已打开的模型列表关闭，且用户不能改变选择
